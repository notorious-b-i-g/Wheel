# Колесо фортуны (Wheel of Fortune)

Telegram Mini App — игра с розыгрышем призов через вращение колеса фортуны, построенная на Django.

> Скриншоты: добавить

## О проекте

«Колесо фортуны» — это Telegram Mini App, в котором пользователь крутит колесо и выигрывает призы. Розыгрыш приза выполняется на сервере по взвешенной вероятности: каждому призу задаётся вес, и итог определяется случайным выбором с учётом этих весов. Поддерживаются реферальные бонусы (за активацию чужого реферального кода начисляется дополнительное вращение) и аутентификация через подпись `initData` Telegram WebApp (проверка HMAC-SHA256 с использованием токена бота).

Бэкенд реализован на Django, фронтенд — на HTML/CSS/JS; для слайдера используется небольшая связка Vue 3 + Swiper.

## Стек

- **Backend:** Python, Django 5.1
- **Frontend:** HTML, CSS, JavaScript; Vue 3 + Swiper (slider)
- **База данных:** MySQL по умолчанию; движок настраивается через переменную окружения `DB_ENGINE` (можно переключить, например, на SQLite)
- **Интеграции:** Telegram Bot / WebApp, внешний API выдачи призов
- **Прочее:** python-dotenv, requests, django-extensions

## Возможности

- Розыгрыш призов по взвешенной вероятности на стороне сервера
- Типы призов, включая бесплатные вращения (freespin) с начислением дополнительных попыток
- Реферальная система: активация реферального кода начисляет бонусное вращение пригласившему и приглашённому
- Аутентификация Telegram WebApp через проверку подписи `initData` (HMAC-SHA256)
- История последних вращений
- Уведомление внешнего API о выигранном призе
- Админ-панель Django для управления призами и пользователями

## Запуск

```bash
# 1. Клонировать репозиторий и перейти в каталог проекта
git clone https://github.com/notorious-b-i-g/Wheel.git
cd Wheel

# 2. Создать и активировать виртуальное окружение
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows (PowerShell):
# .\venv\Scripts\Activate.ps1

# 3. Установить зависимости
pip install django requests python-dotenv django-extensions
# Для MySQL дополнительно: pip install mysqlclient

# 4. Подготовить файл окружения
cp .env.example .env
# затем заполнить значения в .env (см. раздел ниже)

# 5. Применить миграции
python manage.py migrate

# 6. Запустить сервер разработки
python manage.py runserver
```

После запуска приложение будет доступно на `http://127.0.0.1:8000/`.

> Примечание: `requirements.txt` в репозитории пуст. Перечисленные выше пакеты определены по импортам в коде; при необходимости зафиксируйте версии в `requirements.txt`.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения. Файл `.env` в git не попадает.

| Переменная    | Описание                                                            | Пример из `.env.example`        |
| ------------- | ------------------------------------------------------------------- | ------------------------------- |
| `SECRET_KEY`  | Секретный ключ Django                                               | *(задаётся вручную)*            |
| `DEBUG`       | Режим отладки (`True` / `False`)                                    | `False`                         |
| `BOT_TOKEN`   | Токен Telegram-бота; используется для проверки подписи `initData`   | *(задаётся вручную)*            |
| `MODERATOR`   | Ссылка/контакт модератора в Telegram                               | *(задаётся вручную)*            |
| `API_URL`     | URL внешнего API для уведомления о выигранном призе                 | *(задаётся вручную)*            |
| `DB_ENGINE`   | Движок базы данных Django                                           | `django.db.backends.mysql`      |
| `DB_NAME`     | Имя базы данных                                                     | `luckywheel`                    |
| `DB_USER`     | Пользователь базы данных                                            | `root`                          |
| `DB_PASSWORD` | Пароль пользователя базы данных                                     | *(задаётся вручную)*            |
| `DB_HOST`     | Хост базы данных                                                    | `localhost`                     |
| `DB_PORT`     | Порт базы данных                                                    | `3306`                          |
